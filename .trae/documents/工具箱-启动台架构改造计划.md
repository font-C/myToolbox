# 工具箱：启动台（Launchpad）架构改造计划

## 摘要
把当前单工具的「PDF 裁剪」Tauri 桌面应用改造成名为 **工具箱**、带 **macOS 启动台风格首页** 的可扩展多工具应用，并在单窗口内切换首页与工具视图。PDF 裁剪工具保留为其中一个工具。应用做**全面重命名**为「工具箱 / toolbox」。

## 采用的技术决策（已与用户确认）
1. **导航模型**：单窗口内切换。首页（启动台网格）↔ 工具视图，工具内左上角「← 返回」回首页。
2. **改名深度**：全面重命名。含 tauri `productName`、窗口标题、`identifier`、Cargo 包名、Rust lib 名、`package.json` name、`index.html` 标题；Rust 二进制名随之改为 `toolbox`。

## 目标架构
```
App.vue（外壳）
 ├─ 无当前工具 → <HomePage/>（启动台网格，数据来自 tools/registry.js）
 └─ 有当前工具 → 顶部「← 返回」栏 + <component :is="activeTool.component"/>（懒加载）
```
- 工具清单集中在 `tools/registry.js`，后续扩展只需往数组追加一项。
- 当前工具 id 存于新增的 Pinia `stores/app.js`，任何工具均可调用 `goHome()` 返回。

## 具体改动
### 1. 新增 `src/tools/registry.js`（工具注册表，扩展点）
- 导出 `tools` 数组，每项 `{ id, name, desc, icon, component }`。
- `component` 用懒加载工厂：`() => import('../views/CropTool.vue')`。
- 首项：`{ id: 'pdf-crop', name: 'PDF 裁剪', desc: '框选裁剪 PDF 页面', icon: '✂️', component: () => import('../views/CropTool.vue') }`。
- 导出 `getTool(id)`（找不到返回 undefined）。

### 2. 新增 `src/stores/app.js`（当前工具状态）
- `activeToolId: ref(null)`；`activeTool` 计算属性 = `getTool(activeToolId)`。
- action `openTool(id)`、`goHome()`。
- 不重置 pdf store（返回后再进入可保留上次裁剪状态）。

### 3. 新增 `src/views/HomePage.vue`（启动台首页）
- 全屏容器，居中 `display:flex` 网格（`flex-wrap`，固定间距），macOS 启动台风格：
  - 顶部标题「工具箱」+ 副标题「选择要使用的工具」。
  - 背景浅淡（半透明 + `backdrop-filter: blur`，沿用 `--c-bg/--c-primary` 系列）。
  - 每个工具一张卡片：`✂️` 图标（圆角白色方块 Tile）+ 下方工具名；hover 上浮 + 轻微放大 + 阴影，蓝色调圆角。
  - 卡片点击 → `store.openTool(tool.id)`。
- 从 `registry.js` 的 `tools` 数组 `v-for` 渲染（天然可扩展）。

### 4. 修改 `src/App.vue`（外壳 + 导航）
- 移除 `import CropTool` 的固定渲染。
- 引入 `useAppStore` 与 `getTool`。
- 模板：
  - `activeTool` undefined → `<HomePage/>`。
  - 否则 → 顶部工具栏（`← 返回` 按钮 → `goHome()` + `activeTool.name`），下方 `<component :is="activeTool.component"/>`。
- `CropTool.vue` 自带 header 保留不动（工具内操作控件），全局返回栏与工具 header 共存，职责清晰。

### 5. 全面重命名（显示 + 内部，中文显示名「工具箱」/英文串 `toolbox`）
- `src-tauri/tauri.conf.json`：`productName` → `"工具箱"`，窗口 `title` → `"工具箱"`（保留 label 即 `"main"`，capabilities 里的 `"main"` 保持不变），`identifier` → `"com.local.toolbox"`。
- `src-tauri/Cargo.toml`：`[package] name` → `"toolbox"`，`description` → `"本地工具箱（含 PDF 裁剪）"`；`[lib] name` → `"toolbox_lib"`。
- `src-tauri/src/main.rs`：`pdf_crop_desktop_lib::run()` → `toolbox_lib::run()`。
- `package.json`：`name` → `"toolbox"`。
- `index.html`：`<title>工具箱</title>`。
- 保持 `CropTool.vue` 内部标题「PDF 裁剪工具」不变（作为工具名）。

## 假设与说明
- 不引入 vue-router，用 Pinia 单 store 切换视图即可满足「单窗口切换 + 可扩展」，避免额外路由依赖。
- 工具图标暂用 emoji，扩展时可在 registry 中替换为自定义 SVG 或组件，不影响结构。
- 全面改名后打包产物为 `工具箱.app`（旧 `PdfCropTool.app` 需手动删除，避免混淆）。

1. `npm run dev`（浏览器）：

   - PDF 上传、框选、导出、打印功能不受影响（可在浏览器验证导出/打印）。

3. `npm run tauri build`：产物为 `工具箱.app`；打开后首页网格 → 进入工具 → 返回，均正常。
4. 清理旧的 `src-tauri/target/release/bundle/macos/PdfCropTool.app`。
