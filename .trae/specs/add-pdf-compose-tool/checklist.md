# Checklist

- [x] 图片与多个 PDF 可混合导入，每个图片生成 1 个元素、每个 PDF 每页生成 1 个元素
- [x] 导入后默认每个元素单独占一页（输出页），页数等于元素总数
- [x] 元素可在输出页内拖动改变位置
- [x] 元素可通过 8 个角点/边中控点改变大小，且边界在页面范围内
- [x] 元素可跨页拖拽移动到其它输出页；目标页不存在时新建
- [x] 元素可被删除且不影响其它元素
- [x] 输出页支持新增、删除、排序、尺寸配置；归一化坐标不受页尺寸变化影响
- [x] 遮盖标注：框选后可生成不透明白矩形，并支持叠加黑色文字（白底黑字）
- [x] 马赛克标注：框选后生成马赛克打码区域
- [x] 标注可被删除
- [x] 含马赛克的页面导出/打印时以整页位图输出，其余页保持矢量
- [x] 「直接打印」走现有 `print_pdf` 原生链路（浏览器走 `window.print` 兜底）
- [x] 「完整导出」走现有 `save_bytes`（Tauri）或浏览器下载，生成合并后的 PDF
- [x] 空工程（无元素）时打印/导出被禁用并提示
- [x] 工具已在启动台注册且可打开，现有「PDF 裁剪」「口算练习」不受影响
- [x] `npm run build` 通过，无控制台报错
